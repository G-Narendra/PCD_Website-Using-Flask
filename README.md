## 🎯 Problem Statement

This repository is intended to be the web interface for the Pancreatic Cancer Detection project — a Flask-based web app that allows users to upload medical scans and receive AI-powered predictions.

---

## 🧠 Current Status

**This repo is currently empty.** The actual web interface was implemented in the [`Pancreatic-Cancer-Detection-AI`](https://github.com/G-Narendra/Pancreatic-Cancer-Detection-AI) repository, which includes both the Flask backend and React frontend.
